# 短视频水印工具

一个纯前端的单文件小工具：给短视频盖上水印，直接导出 MP4。所有处理都在你自己的浏览器里完成，视频不会上传到任何服务器。

在线使用：<https://tom61-bl.github.io/video-watermark-tool/>

## 能做什么

- **内置水印**：打开即用，不需要另外准备水印图片
- **九宫格定位**：左上、上中、右上、左中、居中、右中、左下、下中、右下
- **三项调节**：水印大小（占画面宽度的 5%–80%）、边缘距离（0–120 px）、不透明度（10%–100%）
- **逐帧精确渲染**：按原速逐帧绘制，输出分辨率与源片一致，画质不降级
- **60fps 稳定导出**：WebCodecs + mp4-muxer，视频用恒定码率（CBR）编码，文件大小可预期
- **保留原声**：源片有音轨就一并重新采样编码进 MP4
- **配置记忆**：位置、大小、边距、透明度存在本机浏览器里，下次打开沿用上次设置

## 怎么用

1. 把视频拖进预览区，或点击选择文件
2. 在右侧九宫格里点选水印位置，再拖三个滑块微调大小、边距、透明度
3. 点「开始生成」，等待进度条走完
4. 点「下载视频」拿到成片，「再做一个」可以继续处理下一条

## 浏览器要求

需要支持 WebCodecs 的浏览器，推荐 **Chrome / Edge 94+**。页面必须在 https 或 localhost 下打开（浏览器只在安全上下文中提供 WebCodecs），本项目的 GitHub Pages 地址已满足这一条件。

Firefox、Safari 对 `VideoEncoder` 的 H.264 支持尚不完整，导出可能失败。

## 技术实现

- 单文件 HTML，无构建步骤，无外部 CDN 依赖
- 水印以 base64 PNG 内嵌，mp4-muxer 5.2.0 已内联
- 编码链路：`seek` 定位每一帧 → `drawImage` 绘制到缓存画布 → `VideoEncoder`（avc, CBR）→ `mp4-muxer` 封装
- 音频链路：`decodeAudioData` 解码 → `OfflineAudioContext` 重采样到 48kHz 立体声 → `AudioEncoder`（AAC）
- 逐帧步长为 1/60 秒，时间戳用 `firstTimestampBehavior: 'offset'` 归零，保证首帧 DTS 为 0
