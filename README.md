# 短视频水印工具

一个纯前端的单文件小工具：给短视频盖上水印，直接导出 MP4。所有处理都在你自己的浏览器里完成，视频不会上传到任何服务器。

在线使用：<https://tom61-bl.github.io/video-watermark-tool/>

## 能做什么

- **内置水印**：打开即用，不需要另外准备水印图片
- **九宫格定位**：左上、上中、右上、左中、居中、右中、左下、下中、右下
- **三项调节**：水印大小（占画面宽度的 5%–80%）、边缘距离（0–120 px）、不透明度（10%–100%）
- **帧率跟随源片**：先探测源片真实帧率（24/25/30/60），按它的帧周期逐帧步进。不再把 30fps 素材硬补成 60fps——补帧等于每两帧重复一次，看起来就是一顿一顿的
- **画质优先的 VBR**：`bitrateMode:variable` + `latencyMode:quality`，静态镜头不再被硬塞冗余码率，运动镜头也不会被摊薄
- **可选输出清晰度**：跟源片一致 / 长边 2560 / 长边 3840，等比放大不裁剪、不变形（放大只提高像素尺寸，补不出源片没有的细节）
- **保留原声**：源片有音轨就一并重新采样编码进 MP4
- **配置记忆**：位置、大小、边距、透明度、清晰度存在本机浏览器里，下次打开沿用上次设置

## 怎么用

1. 把视频拖进预览区，或点击选择文件
2. 在右侧九宫格里点选水印位置，再拖三个滑块微调大小、边距、透明度；需要更大像素尺寸就在「输出清晰度」里选长边
3. 点「开始生成」，等待进度条走完
4. 点「下载视频」拿到成片，「再做一个」可以继续处理下一条

## 出片后怎么看效果

结果区会给出：输出分辨率、帧率、编码器档位、帧数、实际视频码率（括号里是目标码率），以及两个异常计数：

- **解码超时补帧**：某帧 seek 超时没解出来，重试后仍失败，画面会重复一帧。这个数应该是 0，长期大于 0 说明源片 seek 太慢，建议先转成 faststart MP4
- **编码失败帧**：`VideoEncoder.encode()` 抛错被跳过的帧数，正常应为 0

## 浏览器要求

需要支持 WebCodecs 的浏览器，推荐 **Chrome / Edge 94+**。页面必须在 https 或 localhost 下打开（浏览器只在安全上下文中提供 WebCodecs），本项目的 GitHub Pages 地址已满足这一条件。

Firefox、Safari 对 `VideoEncoder` 的 H.264 支持尚不完整，导出可能失败。

## 技术实现

- 单文件 HTML，无构建步骤，无外部 CDN 依赖
- 水印以 base64 PNG 内嵌，mp4-muxer 5.2.0 已内联
- 帧率探测：`requestVideoFrameCallback` 短播 0.3 秒，用 `mediaTime` 差值估算，命中最近的标准帧率
- 编码链路：`seek` 定位到帧边界 → `drawImage` 绘制到缓存画布 → `VideoEncoder`（avc, VBR）→ `mp4-muxer` 封装
- 音频链路：`decodeAudioData` 解码 → `OfflineAudioContext` 重采样到 48kHz 立体声 → `AudioEncoder`（AAC）
- muxer 的视频 timescale 取探测到的帧率，一帧一个 tick，避免 timescale=60 时 24/30fps 变成 2/3 tick 交替
- 时间戳用 `firstTimestampBehavior: 'offset'` 归零，保证首帧 DTS 为 0
